# Shoot Teleport

A 2D Unity game prototype built with Unity 6.

## Requirements

- Unity Hub
- Unity Editor **6000.3.29f1**
- Git
- Git LFS

## Clone the project

Install Git LFS, then clone the repository:

```bash
git lfs install
git clone https://github.com/azern32/Shoot-Teleport.git
cd Shoot-Teleport
git lfs pull
```

Do not copy or open the repository folder through Unity before cloning is complete.

## Open in Unity

1. Open Unity Hub.
2. Click **Add**, then select **Add project from disk**.
3. Choose the cloned `Shoot-Teleport` folder.
4. Open the project using Unity Editor `6000.3.29f1`.
5. Open `Assets/Scenes/DevScene.unity` or `Assets/Scenes/SampleScene.unity`.
6. Press **Play** in the Unity Editor.

## Controls

- **A / Left Arrow**: Move left
- **D / Right Arrow**: Move right
